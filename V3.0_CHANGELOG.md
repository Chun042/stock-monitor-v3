# Stock Monitor V3.0

- Multi-market watchlist: Taiwan stocks and US stocks.
- Independent named browser profiles; up to 30 symbols per profile.
- Add/remove symbols through the dashboard and Cloudflare Worker.
- Multi-symbol daily market snapshots in `docs/stocks.json`.
- Reuse the existing technical-indicator engine for all symbols.
- Switch the candlestick chart, volume histogram and MA overlays by selecting a watchlist row.
- Store holdings quantity and average cost per profile; estimate unrealized P/L from the latest published close.
- Add D1 tables and migration for watchlists and holdings.
- Preserve the original TSMC 2330 data pipeline, FinMind fundamentals/institutional data, and existing push settings.
